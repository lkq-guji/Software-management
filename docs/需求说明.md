# 教学工作量管理系统需求说明（基线 v0.1）

## 业务背景
教师教学任务通常由课程、课时数和班级数构成。系统提供示例数据汇总能力，辅助验证教学工作量计算过程。

## 功能需求
- FR-01：从 CSV 读取字段 teacher、course、hours、classes。
- FR-02：校验教师名、课程名非空，课时和班级数为正整数。
- FR-03：按教师汇总工作量，单条工作量=hours×classes。
- FR-04：命令行支持按教师查询、输出 CSV 结果。
- FR-05：后续由功能负责人扩展按课程统计功能。

## 验收标准
运行 `python app.py summary --file data/workload.csv` 可正确输出三位教师的统计结果；运行 `python -m unittest discover -s tests -v` 全部基线测试通过。

## 实验边界
虚拟数据，不连接真实教务数据库；不涉及学生隐私、权限管理及生产部署。
